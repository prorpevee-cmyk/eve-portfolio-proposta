# portfólio-proposta

Site de apresentação, portfólio e proposta comercial da Evelyn.

## Abrir o site

Baixe o repositório e abra `index.html` no navegador. Para uma prévia local com Python:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Acesse http://127.0.0.1:4173/.

## Conteúdo

- `index.html`: textos, seções, pacotes e contatos.
- `styles.css`: identidade visual e layout responsivo.
- `portfolio.js`: navegação do carrossel.
- `assets/`: imagens utilizadas pelo site.

O repositório não inclui publicação automática.
